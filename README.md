# Akansha — Portfolio

My personal site: a warm, minimal portfolio with live GitHub stats and a fully interactive terminal (press `` ` `` anywhere, or `⌘K` for the command palette).

Built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

## Highlights

- **Interactive terminal** — type `help` to explore; `ls`, `open <project>`, `stats`, `theme`, and more.
- **Command palette** — `⌘K` / `Ctrl+K` to jump anywhere.
- **Live stats** — GitHub followers, repos, and stars pulled at request time.
- **Light & dark themes**, respects your system preference.
- **Case study** — a deeper look at Connexa at `/work/connexa`.

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm test         # vitest
```

## Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion · Vercel
